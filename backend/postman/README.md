# PawMatch Shared Postman Testing Collection

## How to import Postman Shared Testing Collection

To import the Postman collection, click the three dot button that is above the "Collection" tab in Postman, and click the "Import" button in the resulting dropdown options. Then, you can either drag and drop the file from "/backend/postman/PawMatch.postman_collection.json", or select that file when you click "select files or folders".
